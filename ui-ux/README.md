```

│   ├── User-Personas.pdf
```

## Design language

- Brand: **NexPay**
- Primary: `#6366F1` · Accent: `#10B981` · Background: `#05050A`
- Font: Plus Jakarta Sans
- Style: Modern fintech (Stripe / Revolut / Cash App inspired)

## Notes

- PNGs are **1080 × 2400** (mobile presentation size).
- HTML files mirror each PNG and are self-contained for offline preview.
- Open `design-system/index.html` for tokens and components.
